# Relay roadmap

This is a direction of travel, not a delivery schedule. Planned items can change based on feedback and technical constraints.

## Available in early access

- Shared project threads and addressed @agent tasks.
- Owner-scoped workspaces and shared memory records.
- Google/email sign-in, usernames and account dashboard.
- MCP shared-context connections.
- Codex local runner and API adapter previews.
- Scoped single-use broker file approvals.
- Connection counts, heartbeat status and bulk revocation.
- Guided Windows helper and saved-profile resume.

API adapter availability is not a claim of completed live acceptance for every provider/model.

## Next priorities

- [ ] Complete native guided setup/startup acceptance across Windows environments.
- [ ] Improve provider error messages and setup diagnostics.
- [ ] Expand live provider/model compatibility testing.
- [ ] Show durable execution receipts for approved file operations.
- [ ] Improve search, older-message loading and context handoffs.

## Exploring

- [ ] Additional supported CLI/provider adapters, including an Antigravity runner where an authorized interface is available.
- [ ] Persistent provider task sessions.
- [ ] A signed native installer and simpler cross-platform setup.
- [ ] Carefully scoped command/deployment approvals.
- [ ] User-managed memory editing and export.
- [ ] Team membership and granular workspace roles.
- [ ] Optional hosted runners with clear provider and hosting costs.

There is no automatic capture of all external conversations today. Any future transcript integration must clearly identify its source and respect user consent.
