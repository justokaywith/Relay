# Security reporting

Please report suspected vulnerabilities through [GitHub’s private vulnerability reporting form](https://github.com/justokaywith/Relay/security/advisories/new).

Do not disclose vulnerabilities or credentials in public issues or Discussions. For account/service questions rather than vulnerabilities, contact support@pactuno.online.

Include a concise description, affected feature, reproduction steps using your own test account, expected impact and sanitized evidence. Never include another user’s data or live credentials.

Do not access other accounts, disrupt the service, install malware or test with data you are not authorized to use. No bug bounty payment or response-time guarantee is offered by this repository.

The public repository is documentation-only. A source-code review of these files does not establish that the hosted application is vulnerability-free.
